# GtaViceWeb - Contributing

Contributions are welcome! Please follow these guidelines.

## Code Style

- Follow the existing code style in `CODING_STYLE.md`
- Use 4-space indentation
- Keep lines under 120 characters
- Use descriptive variable/function names

## Areas to Contribute

### High Priority
- Performance optimization
- WebGL compatibility fixes
- Mobile control improvements
- Browser compatibility testing
- Audio system improvements

### Medium Priority
- Additional input methods
- Settings/configuration UI
- Error handling and recovery
- Documentation

### Low Priority
- Cosmetic UI improvements
- Additional visual effects

## Important: No Game Assets

**DO NOT** include or commit:
- .DFF/.TXD files (game models/textures)
- .dat files (game data)
- Audio files from GTA Vice City
- Any copyrighted Rockstar Games content

Contributions including game assets will be rejected.

## Before You Submit

1. Test your changes locally
2. Build with `make build`
3. Test in multiple browsers if possible
4. Check for console errors (F12)
5. Document your changes

## Submission Process

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Commit with clear messages
6. Push to your fork
7. Create a Pull Request
